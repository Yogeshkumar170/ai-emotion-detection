# AI Emotion Detection (Text-Based)

Detect emotions from text input using a **rule-based system** with Python and Flask. Emotions include **happy, sad, angry, surprise, neutral**.

## Features
- Text-based emotion detection
- Built with Python and Flask

## Project Structure

│ └── index.html
